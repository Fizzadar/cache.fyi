# cache.fyi

Cache.fyi is a cache for _my_ information. Cache.fyi is a thing. Cache.fyi does not welcome external contributions (read the blog post).

### What is cache.fyi?

That's a good question, one that has no clear answer (yet). Cache.fyi is evolving from a simple idea "a place to collect stuff". Sort of a mix between a bookmarking service, wiki and RSS reader.

### But why?

Because bookmarking services exist, archiving services exist and wiki services exist. But not together, nor supporting the workflows I desire:

- adding stuff should be minimum or zero additional clicks/taps
    - I want to tap "share" -> "send to cache.fyi" and **nothing else**
    - don't make me tag or think about folder categorization
    - should be so fast and easy that I can chuck anything into the cache without thinking
- store specific bits of content (this image, this paragrph) as well as the full site
    - offload the full site fetch to ArchiveBox
    - use the local browser/device context/share item as the direct content
- automate tagging and section/folder assignment
    - if the url looks like this, place the content at that path
    - use this path as the default
- add commentary and notes around content
    - eg a new macOS setup page text
    - bunch of sub-documents/content linking out to sources
- import RSS feeds into a section/folter
    - document per URL/feed item
